# 满嘴爆米花

满嘴爆米花是一个面向家庭、情侣、养宠家庭与亲密小圈子的共同生活管理小程序。

项目的核心不是单一的库存清单，而是一个可共享的生活空间：成员可以管理家庭物品和有效期、宠物档案、个人健康数据、菜谱与菜单、生活点滴，以及重要的图文记录。

当前仓库是微信小程序前端工程。服务端将以独立的 Go 工程维护，并通过版本化 HTTP API 与本工程通信。

## 技术决策

- 前端：微信原生小程序，使用 TypeScript、WXML 和 WXSS。
- 后端：独立 Go 模块化单体服务，不使用旧版微信云函数实现。
- 数据库：PostgreSQL。
- 文件存储：腾讯云 COS；私有用户内容通过短期签名 URL 访问。
- 部署：Docker 容器，GitHub Actions 构建并发布到腾讯云环境。

## 本地开发

后续创建 `miniprogram/` 源码目录后，使用微信开发者工具导入本目录，并按项目配置运行。小程序包由微信平台编译和发布；CDN 不用于承载小程序代码，只用于公共静态资源或未来的 Web 站点。

## 仓库边界

本仓库只维护小程序客户端。建议创建配套的 `popcorn-server` 仓库，用于维护 Go API、数据库迁移、Docker 镜像和服务器部署配置。
