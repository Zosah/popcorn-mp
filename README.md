# 时刻在

> 我回来啦，把日子安放在一起。

时刻在是一个面向家庭、情侣、养宠家庭与亲密小圈子的共同生活管理小程序。

项目的核心不是单一的库存清单，而是一个可共享的生活空间：成员可以管理家庭物品和有效期、宠物档案、个人健康数据、菜谱与菜单、生活点滴，以及重要的图文记录。

当前仓库是微信小程序前端工程。服务端将以独立的 Go 工程维护，并通过版本化 HTTP API 与本工程通信。

## 当前状态

项目已完成 Demo 0.9：以“家”为首页，采用轻盈可爱的生活状态卡片，提供库存完整本地闭环、多个宠物档案切换、宠物事件新增/详情/编辑/删除与月历、持续照护、每日吃喝拉撒记录、宠物食品和猫砂集合、菜单体验、生活记录新增、提醒设置、共同空间、成员信息，以及邀请码与微信分享路径的本地邀请体验。自定义底部导航已统一适配安全区，子页面支持可靠返回。旧版小程序和云函数实现已移除；以下文档是后续开发的设计依据。

## 技术决策

- 前端：微信原生小程序，使用 TypeScript、WXML 和 WXSS。
- 后端：独立 Go 模块化单体服务，不使用旧版微信云函数实现。
- 数据库：复用现有服务器 MySQL，使用独立数据库和独立账号。
- 文件存储：已有腾讯云 COS；MVP 先用于数据库备份，图片能力延后接入。
- 部署：不依赖本地 Docker。GitHub Actions 构建 Linux 二进制，已有服务器通过 systemd 运行 Go API，Caddy 或 Nginx 提供 HTTPS。

## 本地开发

使用微信开发者工具导入本目录即可运行 Demo。首次拉取后执行：

```bash
npm install
npm test
npm run typecheck
```

当前 Demo 使用小程序本地存储与页面内示例状态，不依赖后端。库存、多个宠物档案、宠物事件与月历、用品集合、生活记录和提醒设置可在本地交互；菜单页用于验证完整产品体验。小程序包由微信平台编译和发布；CDN 不用于承载小程序代码，只用于公共静态资源或未来的 Web 站点。

## 仓库边界

本仓库只维护小程序客户端。配套的 `popcorn-server` 仓库用于维护 Go API、数据库迁移、Linux 发布产物和 systemd 服务器部署配置。
