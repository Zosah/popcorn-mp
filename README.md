# 时刻在

> 我回来啦，把日子安放在一起。

时刻在是一个面向家庭、情侣、养宠家庭与亲密小圈子的共同生活管理小程序。

项目的核心不是单一的库存清单，而是一个可共享的生活空间：成员可以管理家庭物品和有效期、宠物档案、个人健康数据、菜谱与菜单、生活点滴，以及重要的图文记录。

当前仓库是微信小程序前端工程。服务端将以独立的 Go 工程维护，并通过版本化 HTTP API 与本工程通信。

## 当前状态

项目已完成前端 MVP Demo 1.1：以“家”为首页，采用 v4.6「冷柔光纸面」视觉。库存、多个宠物档案与事件月历、持续照护、每日吃喝拉撒、宠物用品、菜谱菜单、生活点滴、重要记录、待办与小计划、提醒设置、共同空间与邀请体验均已形成可操作的本地 Demo 闭环；待办页统一承载旅行准备清单、小计划、健身与热量粗算、今天吃什么推荐和共同账单，食材备料、人份、待办完成状态和提醒偏好刷新后仍会保留，并支持一键恢复 Demo 初始数据。统一细线图标覆盖 TabBar、长列表、表单和详情页，自定义底部导航已适配安全区。当前仍未接后端，所有数据只保存在本机；旧版小程序和云函数实现已移除。

## 技术决策

- 前端：微信原生小程序，使用 TypeScript、WXML 和 WXSS。
- 后端：独立 Go 模块化单体服务，不使用旧版微信云函数实现。
- 数据库：复用现有服务器 MySQL，使用独立数据库和独立账号。
- 文件存储：已有腾讯云 COS；MVP 先用于数据库备份，图片能力延后接入。
- 部署：不依赖本地 Docker。GitHub Actions 构建 Linux 二进制，已有服务器通过 systemd 运行 Go API，Caddy 或 Nginx 提供 HTTPS。

## 本地开发

使用微信开发者工具导入本目录即可运行 Demo。首次拉取后执行：

```bash
npm install
npm test
npm run typecheck
npm run verify:demo  # 需先开启开发者工具自动化端口
```

当前 Demo 使用小程序本地存储与页面内示例状态，不依赖后端。库存、多个宠物档案、宠物事件与月历、用品集合、菜单、生活记录／重要记录、待办与小计划和提醒设置都可在本地完整操作。小程序包由微信平台编译和发布；CDN 不用于承载小程序代码，只用于公共静态资源或未来的 Web 站点。

## 仓库边界

本仓库只维护小程序客户端。配套的 `popcorn-server` 仓库用于维护 Go API、数据库迁移、Linux 发布产物和 systemd 服务器部署配置。
