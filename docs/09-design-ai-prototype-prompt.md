## 一、产品定位

「时刻见」是一款面向情侣、夫妻、室友和小家庭的共同生活小程序。

它围绕一个「共同空间」，帮助两个人记录生活、管理家里的物品和待办、决定吃什么，以及照顾宠物。

一句话概括：

> 把普通日子里的记录、家务、计划和陪伴，安放在一起。

产品不是聊天工具，也不是纯效率工具。它更像两个人共同维护的一本生活手账，同时具备轻量的管理和提醒能力。

## 二、目标用户

- 情侣或夫妻
- 合租室友
- 一两个人在外生活的小家庭
- 养宠物的年轻用户
- 希望记录生活，但不想使用复杂工具的人

早期通常只有 1～2 个用户共同使用，但后续可能扩展到更多家庭成员。

## 三、核心产品模型

```text
微信账号
  └─ 共同空间
       ├─ 空间成员与邀请
       ├─ 生活记录
       ├─ 家庭库存
       ├─ 待办与小计划
       ├─ 菜单 / 今天吃什么
       └─ 宠物照护
```

首页可以作为共同生活的聚合入口，用于集中呈现空间内的近期状态和常用功能。但它具体呈现什么、怎么组织，由设计自行决定。

## 四、核心功能

### 1. 账号与共同空间

- 微信登录
- 创建和编辑昵称
- 选择简单头像样式
- 登录状态恢复
- 退出登录
- 默认共同空间
- 当前空间信息
- 空间名称修改
- 空间成员列表
- Owner / Member 身份
- 生成邀请码
- 复制或分享邀请
- 输入邀请码加入空间
- 邀请码单次使用、限时有效

核心目的：让两个人或一个小家庭共享同一份生活数据。

### 2. 首页聚合

首页可以汇总空间内的部分或全部生活信息，包括：

- 当前空间和成员
- 最近的生活记录
- 家庭库存变化或临期状态
- 待办和计划进度
- 菜单或今天吃什么
- 宠物动态和照护状态
- 常用功能入口

这些内容是否需要全部出现、以什么顺序出现，由设计自行判断。

### 3. 生活记录

记录类型：

- 生活点滴
- 重要记录

能力包括：

- 新建、编辑、查看和删除记录
- 标题、正文和记录日期
- 单张图片和图片说明
- 图片预览
- 重要记录分类
  - 家的资料
  - 健康资料
  - 宠物资料
  - 其他资料
- 可见范围
  - 空间成员可见
  - 仅自己可见

核心目的：同时满足日常记录、长期资料保存和私密内容管理。

### 4. 家庭库存

能力包括：

- 查看物品列表和搜索物品
- 新增、编辑、查看和删除物品
- 数量与单位
- 分类
- 存放位置
- 购买日期
- 开封日期
- 到期日期
- 当前库存和历史记录
- 有效期筛选
  - 全部
  - 已过期
  - 三天内到期
  - 七天内到期
  - 无有效期
- 生命周期操作
  - 消耗
  - 丢弃
  - 归档
  - 恢复

物品分类：

- 食品
- 饮料
- 冷冻
- 调料
- 日用品
- 药品
- 宠物用品
- 其他

存放位置：

- 冰箱冷藏
- 冰箱冷冻
- 厨房
- 客厅
- 卫生间
- 储物间
- 其他

核心目的：让用户快速知道家里有什么、放在哪里、是否快过期。

### 5. 待办与小计划

统一管理生活中的轻量安排，分为五类：

#### 旅行准备

- 目的地
- 截止日期
- 准备清单
- 逐项勾选
- 清单完成进度

#### 小计划

- 标题
- 备注
- 计划日期
- 完成状态

#### 健身

- 运动名称
- 运动时长
- 热量估算

#### 今天吃什么

- 早餐、午餐、晚餐、加餐
- 随机推荐
- 生成一条饮食安排

#### 我们的账单

- 金额
- 购买地点
- 备注
- 总支出统计

通用能力：

- 分类筛选
- 新增、编辑和删除
- 完成与重新打开
- 截止日期
- 待办进度
- 未完成数量统计
- 过期状态

产品规则：

- 账单创建后默认视为完成
- 账单不计入未完成待办

### 6. 菜单 / 今天吃什么

菜单用于保存常做的菜、食材和烹饪过程。

能力包括：

- 菜单列表
- 今日、全部和本周视图
- 推荐菜单
- 新建、编辑和删除菜单
- 菜名和描述
- 用餐人数
- 烹饪时长
- 食材清单
  - 名称
  - 用量
  - 来源
  - 是否备齐
- 烹饪步骤
- 调整用餐人数
- 查看菜品详情
- 开始做饭前检查食材准备情况

需要区分：

- 菜单：菜谱、食材和步骤。
- 今天吃什么：待办中的一种饮食安排。

两者概念相关，但目前是独立数据。

### 7. 宠物照护

能力包括：

- 多宠物切换和添加宠物
- 宠物基础档案
  - 名字
  - 猫、狗或其他
  - 品种
  - 性别
  - 生日
  - 到家日期
  - 绝育日期
- 体重记录和趋势
- 宠物事件
  - 疫苗
  - 绝育
  - 洗护
  - 生病
  - 就诊
  - 外出
  - 体内驱虫
  - 体外驱虫
- 宠物事件新增、编辑、详情和删除
- 下一次照护日期
- 宠物日历
- 周期照护
  - 体内驱虫每 90 天
  - 体外驱虫每 30 天
- 每日记录
  - 吃饭
  - 喝水
  - 便便
  - 尿尿
- 宠物用品
  - 主粮
  - 罐头
  - 冻干
  - 汤包
  - 猫砂
- 用品状态
  - 正在用
  - 爱吃 / 好用
  - 吃过 / 用过
  - 种草
  - 拔草

### 8. 我的与设置

- 当前账号和资料
- 当前共同空间
- 空间成员
- 待办完成进度
- 账号与登录
- 共同空间管理
- 成员与邀请
- 隐私与可见范围
- 提醒偏好
- 底部导航自定义
- Demo 数据重置

### 9. 底部导航自定义

当前产品支持 4 个底部位置：

- 第 1 位固定为「家」
- 第 4 位固定为「我的」
- 第 2、3 位可由用户选择

一级入口候选：

- 宠物
- 生活记录
- 待办与小计划
- 今天吃什么
- 家庭库存

二级入口候选：

- 宠物照护
- 宠物日常
- 旅行准备
- 小计划
- 健身计划
- 我们的账单

二级入口通过现有页面直接进入具体场景。

同一功能不能同时占用两个底部位置。

具体如何呈现自定义能力，可以由设计自行决定。

## 五、核心功能关系

### 共同空间

```text
共同空间
├─ 账号与成员
├─ 生活记录
├─ 家庭库存
└─ 待办与小计划
```

这些内容可以跨成员共享。

生活记录额外支持「仅自己可见」。

### 首页

首页是聚合层，可以组合展示：

```text
首页
├─ 空间与成员
├─ 最近生活记录
├─ 库存和临期状态
├─ 待办进度
├─ 菜单摘要
└─ 宠物动态与照护状态
```

### 待办与菜单

```text
待办
└─ 今天吃什么
   ├─ 随机推荐一餐
   └─ 生成饮食安排

菜单
├─ 保存菜谱
├─ 食材清单
└─ 烹饪步骤
```

两者相关，但当前没有实体绑定。

### 库存、菜单和宠物用品

```text
菜单食材
宠物用品
家庭库存
```

目前是三套独立数据。

产品边界：

- 菜单食材不会自动扣减家庭库存。
- 宠物用品不等于家庭库存。
- 生活记录中的宠物分类不是宠物档案。
- 宠物事件不会自动生成待办。

### 提醒

当前提醒能力包括：

- 库存临期提醒偏好
- 宠物照护提醒偏好
- 每周回顾偏好
- 默认提醒时间

目前这些只是本机偏好，不代表已经完整接入微信订阅消息。
