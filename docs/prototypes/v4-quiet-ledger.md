# 「时刻见」v4 视觉方向：静默账本

## 方向

- 暖灰纸面 `#f4f3f1`，正文接近墨色，所有界面装饰保持无彩色。
- 深赭 `#743e37` 只用于日期、过期数量和风险状态，不用于按钮与导航。
- 日期数字使用宋体，正文继续使用系统中文字体。
- 主要层级依靠字号、留白和细线，不依靠卡片、阴影和彩色图标块。
- 主操作使用近黑描边或实心按钮，TabBar 选中态保持墨色。

## 技能验证

- `design-taste-frontend`：抽取视觉方向、静态 lint、浏览器检查、390px 截图复核。
- lint：0 FAIL，0 WARN。
- inspect：0 FAIL，2 个非阻塞提示（移动端小字号密度、强调色占比统计）。
- `frontend-design`：用于约束主题相关性、字体层级与去模板化。
- `design-mobile-apps`：已安装，但依赖 Sleek API 与额度，本轮未使用。

## 页面

- 首页：日期作为唯一视觉锚点；待处理数量使用单一风险色；常用入口改为文字账本行。
- 库存：统计、筛选、搜索与物品列表共用一条左对齐基线；不使用卡片分组和悬浮按钮。
- 记录：保留时间轴，但将卡片拆分细线行；照片成为唯一的大色块。
