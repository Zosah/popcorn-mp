# v4.3 视觉稿自查

## 第一眼

- 视觉锚点：首页的大日期、待处理数量和一处生活记录影像。
- 产品身份：时间、家庭库存、生活记录和宠物照护共用同一套“家庭账本”结构。
- 首屏任务：知道今天要处理什么，并能直接进入库存。
- 影像原则：叙事图片是内容，不是装饰；每页最多一处，信息页保持无图。
- 插画原则：小幅插画只服务空态、邀请和身份收尾，统一深赭墨色，不让每页都变成图册。
- 图标原则：统一细线、四种色调，承担识别而非装饰；文字始终保留，常规区域维持 22–32rpx。

## 当前风险

1. 辅助信息在窄屏上多为 9–11px，需在微信真机再次检查可读性。
2. 公版艺术与最终品牌摄影/插画之间仍有气质差距，正式上线前应统一替换。
3. 菜单示例静物与“番茄牛腩”并非同一道菜，只用于验证版式，不能作为真实菜单图片。
4. 图片资源约 0.9 MB，功能图标 PNG 约 432 KB，全部在主包；后续新增视觉资源前需要核算包体与首屏下载成本。
5. 当前仍为本机 Demo，所有数据均未接入后端。
6. 图标目前按四种色调分别打包，后续若包体接近上限，可先收敛实际使用色调或改为字体/代码绘制方案。
