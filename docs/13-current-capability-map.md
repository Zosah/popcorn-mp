# 时刻见｜当前能力清单

> 用途：交给设计 Agent 重新设计小程序的 UI 与交互。
>
> 版本：v1.53.0（2026-11-03）
>
> 本文只整理当前已经具备的用户能力、对象关系和关键流程，不约束首页布局、页面结构、视觉风格、导航形式或组件样式。设计可以重新组织信息架构，但需要保留这些能力和共同空间关系。

## 1. 产品定位

「时刻见」是一款面向情侣、夫妻、室友和小家庭的共同生活小程序。

产品围绕一个「共同空间」，把生活记录、家里的物品、待办、吃饭、账单、旅行、健身和宠物照护放在一起。

它不强调复杂效率和任务管理，更接近两个人一起维护的生活手账，同时具备轻量管理能力。

当前主要供 1～2 人使用，产品结构需要为之后增加成员和更多生活场景保留扩展空间。

## 2. 核心产品模型

```text
微信用户
  └─ 共同空间（可加入多个，每次只进入一个）
       ├─ 成员与邀请
       ├─ 记录
       ├─ 库存
       ├─ 待办
       ├─ 下厨
       ├─ 宠物
       ├─ 旅行
       ├─ 健身
       └─ 账单
```

- **共同空间是数据边界**：库存、记录、待办、下厨、宠物等内容都属于当前空间。
- **用户可以加入多个空间**，并设置默认空间、随时切换。
- **每位成员可以有自己的首页快捷位和底部导航配置**，配置按「空间 + 用户」保存。
- **记录支持共享与私密两种可见范围**。
- **宠物是共同生活里的成员对象**，不是普通工具。
- **旅行、健身、账单与待办共用底层能力，但对外是三个独立功能**，不应设计成待办里的五个子 Tab。

## 3. 当前功能总览

| 分类 | 功能 | 主要作用 |
| --- | --- | --- |
| 工具 | 库存 | 家里有什么、放在哪里、什么时候过期、是否已经用完 |
| 工具 | 账单 | 记录花了多少钱、买了什么，查看月度支出 |
| 工具 | 下厨 | 菜谱、分类、一起点菜、备菜、做饭和吃完归档 |
| 生活 | 旅行 | 目的地、出发准备事项和清单进度 |
| 生活 | 健身 | 运动、时长、热量和完成记录 |
| 备忘 | 记录 | 生活点滴、图片和重要资料 |
| 备忘 | 待办 | 日常 TODO、标签分组和完成进度 |
| 成员 | 宠物 | 宠物档案、日常、用品、护理、体重和时间线 |

全局页面：

- **首页**：当前空间的共同生活摘要和快捷入口。
- **我的**：当前空间、成员关系、功能目录和设置入口。
- **设置**：账号与管理、共同空间、功能配置。
- **功能配置**：配置首页 4 个快捷位和底部导航 3 个自定义位。
- **全部功能**：按分类浏览所有功能。

## 4. 账号与共同空间

### 登录与身份

- 微信 `openid` 一键登录；不保存手机号，账号头像保存为私有 COS 媒体，并与共同空间成员共享读取权限。
- 首次登录后可以选择微信头像和昵称。
- 未登录可以关闭登录提示、继续预览。
- 未登录执行写入操作时，再提醒登录。
- 登录后恢复账号、空间和当前使用状态。
- 账号与管理中可以更换头像、查看登录状态和退出登录。

### 空间关系

- 一个用户可以属于多个共同空间。
- 每个空间有自己的名称、头像和成员。
- 支持设置默认空间。
- 支持在首页和空间管理页切换空间。
- 空间角色对外使用「创建人 / 共创人」，不使用 Owner / Member 这类系统词。

### 创建人能力

- 修改空间名称。
- 更换空间头像，只接受 1:1 图片并支持裁剪。
- 生成 10 位一次性邀请码，7 天有效。
- 复制邀请码、通过微信分享邀请。
- 预览邀请页。
- 移除共创人。

### 共创人能力

- 输入邀请码加入他人的空间。
- 查看空间成员和共同内容。
- 退出空间，二次确认后离开。

## 5. 首页

首页是当前空间的生活摘要，不固定具体布局。当前具备以下信息与入口：

- 当前空间名称、日期和成员头像。
- 点击空间名称可以切换空间。
- 问候语和共同记录数量。
- 4 个用户可配置的快捷功能。
- 最近一条生活记录，点击进入记录详情。
- 「今天 / 家里 / 宠物」三个生活场景摘要。
  - 今天：待办完成情况。
  - 家里：库存状态和最近的下厨内容。
  - 宠物：当前宠物状态、最近动态和照护入口。
- 从场景摘要继续进入对应功能。

首页快捷位默认示例为「记录、库存、待办、宠物」，实际以用户配置为准。

## 6. 功能配置与导航

- 当前导航有 5 个入口：
  - 首页固定。
  - 中间 3 个由用户配置。
  - 我的固定。
  - 设计可以重做导航样式和切换方式，但需要保留 3 个可配置入口。
- 首页固定 4 个快捷功能位。
- 当前一级功能共 8 个：库存、账单、下厨、旅行、健身、记录、待办、宠物。
- 每个功能在「首页快捷 + 底部导航」的 7 个位置中只能出现一次。
- 已放入某个位置的功能，在功能池中置灰，不能重复占用其他位置。
- 支持拖拽放入、替换和区域内排序。
- 拖拽只修改草稿，点击保存后统一提交。
- 配置按「空间 + 用户」隔离。
- 支持恢复默认配置。
- 保存后首页快捷位和底部导航立即同步。

功能分类：

- **工具**：库存、账单、下厨。
- **生活**：旅行、健身。
- **备忘**：记录、待办。
- **成员**：宠物。

## 7. 记录

记录同时承载日常内容和需要长期保存的资料。

### 内容类型

- **生活点滴**：日常瞬间、照片和文字。
- **重要记录**：需要以后查找的资料。
- 重要记录分类：
  - 家的资料。
  - 健康资料。
  - 宠物资料。
  - 其他资料。

### 可见范围

- 空间成员可见。
- 仅自己可见。

### 记录能力

- 新建、编辑、查看和删除。
- 标题、正文和记录时间。
- 最多 9 张图片，缩小状态按 1:1 方块展示。
- 第一张图片可以写说明。
- 时间线浏览。
- 图片点击预览。
- 首页展示最近一条记录。

## 8. 库存

用于管理家里的物品、数量、位置和有效期。

### 物品信息

- 名称。
- 分类：食品、饮料、冷冻、调料、日用品、药品、宠物用品、其他。
- 存放位置：冰箱、冷冻、厨房、客厅、卫生间、储藏、其他。
- 数量与单位。
- 购买日期、开封日期、有效期。
- 备注。

### 浏览与操作

- 当前库存 / 历史记录。
- 搜索。
- 有效期筛选：已过期、3 天内、7 天内、无有效期。
- 新增、编辑、查看详情和删除。
- 每件物品可上传 1 张私有图片；列表展示缩略图，详情支持大图预览，编辑时可替换或移除。
- 详情页顶部集中提供编辑、删除，状态操作横向排列。
- 标记为已用完、已丢弃或已归档。
- 历史记录可以恢复。
- 物品数据由空间成员共享。

## 9. 待办

待办只处理需要记住和完成的事项。

### 核心能力

- 新建、编辑、完成、重新打开和删除。
- 标题、备注、截止日期。
- 待完成 / 已完成。
- 待办数量、完成数量和进度。
- 自定义标签，例如「突然想到」「下班买的东西」。
- 标签筛选、新增、重命名和删除。

### 展示关系

- 旅行、健身和账单是首页/底栏中的独立功能入口。
- 它们使用待办的数据能力，但各自有专用表单和语义。
- 不把旅行、健身、账单设计成待办内部的多个子 Tab。
- 「今天吃什么」属于下厨，不属于待办。

## 10. 旅行

- 目的地。
- 截止日期。
- 备注。
- 准备事项清单，每行一项。
- 出发前逐项勾选。
- 清单完成进度。
- 完成或重新打开。

## 11. 健身

- 运动名称。
- 运动时长。
- 热量记录。
- 根据运动类型和时长粗略估算热量，可手动调整。
- 完成或重新打开。

## 12. 账单

- 金额。
- 购买地点。
- 备注。
- 日期。
- 月度支出统计。
- 账单创建后视为已完成，不计入未完成待办。

## 13. 下厨

下厨由「吃啥」和「菜谱本」两个核心场景组成。

### 菜谱

- 菜名、描述、分类。
- 一桌成品图，与菜名、描述并排展示；添加后可在表单内查看或移除。
- 最多 9 张做法参考图，位于做法之后。
- 食材逐行录入：名称、数量步进器、单位选择器和存放来源。
- 做法使用一个多行输入框，每行整理为一步。
- 新增、编辑、查看详情和删除。

### 菜谱分类

- 默认分类：肉类、菜类、汤类、主食、其他。
- 支持新增、重命名和删除分类。
- 菜谱本使用左侧分类导航，始终保留「未分组」。

### 一起点菜

- 菜谱卡展示右上角 1:1 成品图，并提供「+ 吃它」入口。
- 点击后先进入当前用户的本地加购区。
- 同一道菜只占一席，不展示或调整份数。
- 选择早餐、午餐、晚餐或加餐。
- 可以给厨房留言。
- 整桌使用 01、02、03 数字序号展示菜品。
- 底部「选好了」进入整桌确认，提交后生成空间共享的用餐订单。
- 单道菜与整桌都可以删除，删除操作统一使用红色；整桌删除前需要二次确认。

### 共享备菜

- 展示点菜人、时间、餐次、菜品和留言。
- 菜谱行紧凑展示菜谱图、菜名与备齐数量，食材名称与用量同排。
- 空间成员可以共同逐项标记或取消食材已备好。
- 全部备齐后自动折叠食材，仍可手动展开查看。
- 可从备菜行的「看看怎么做」打开做法弹窗查看步骤。
- 订单状态：
  - 待开火。
  - 备菜中。
  - 可以开饭。
  - 已吃完。
- 已吃完的订单进入历史，默认折叠最近记录。

### 做饭

- 从菜谱详情调整人份、勾选食材。
- 进入做饭模式。
- 按步骤导航，逐步完成。
- 本地计时。
- 中途退出保留本机进度，可以继续。
- 完成后展示用时和完成步骤。

### 数据关系

- 提交点菜时保存菜谱标题等快照。
- 后续修改菜谱，不反向修改已经提交的用餐记录。

## 14. 宠物

一个空间可以有多只宠物，并支持切换和新增。

### 宠物展示

- 宠物头像，可点击放大，更换时支持 1:1 裁剪。
- 背景支持 3 个系统主题或上传自定义背景。
- 名字、品种、年龄和当前状态。
- 当前体重、陪伴天数、成长记录数。
- 当前宠物切换。

### 日常

每条操作都应该是独立记录，同一天可以发生多次。

- 吃饭：猫粮、罐头、冻干或其他，可填份量。
- 喝水。
- 便便：正常、偏软、偏硬、异常。
- 尿尿：正常、偏少、偏多或未观察，可填尿团/次数。
- 换猫砂：局部清理或整盆更换。
- 换水：换水、洗水碗或换水并洗，可填几处。
- 今天的记录按时间线展示。

### 用品

- 类型：主粮、罐头、冻干、汤包、猫砂，以及自定义类型。
- 名称、品牌、备注、可选实物图片。
- 喜欢程度：
  - 超爱 ♥♥♥
  - 还行 ♥♥
  - 不爱 ♥
- 按类型筛选。
- 可以修改喜欢程度。

### 护理

周期性照护：

- 洗护、体内驱虫、体外驱虫等。
- 显示距离上次已经过去多久。
- 可以记录本次时间、备注和下次时间。
- 提供照护月历，可以按日期查看和新增事件。

成长事件：

- 疫苗、绝育、洗澡、生病、就诊、外出、驱虫等。
- 日期、标题、备注、机构、费用、下次日期。
- 以时间线展示，超过 5 条时可以折叠。
- 时间线完整展示年月日，不折叠时间。

### 档案

- 出生日期、到家日期。
- 最近疫苗、下次疫苗。
- 绝育情况。
- 体重记录和趋势图。
- 成长时间线，出生和到家是基础节点。
- 超过 5 条时可以折叠。
- 删除宠物档案。

## 15. 我的

- 「我的」页提供设置入口。
- 当前空间卡片：
  - 空间名称和头像。
  - 创建人 / 共创人关系。
  - 成员数、已完成待办、生活记录数。
  - 邀请入口。
- 按生活场景展示功能目录。
- 「查看更多」进入全部功能页。
- 点击空间卡片进入空间管理。
- 设置页包含：账号与管理、共同空间、功能配置。

## 16. 核心对象关系

```text
用户 1 ── N 共同空间
共同空间 1 ── N 成员
共同空间 1 ── N 记录
共同空间 1 ── N 库存物品
共同空间 1 ── N 待办
共同空间 1 ── N 菜谱
共同空间 1 ── N 用餐订单
共同空间 1 ── N 宠物
用户 + 共同空间 1 ── 1 功能配置
```

需要保留的边界：

- 记录可以只给自己看，其余核心内容默认对空间成员可见。
- 菜谱与用餐订单存在快照关系，订单不跟随菜谱后续编辑。
- 库存、菜谱食材、宠物用品目前是三套独立数据，不会自动扣减或同步。
- 记录里的「宠物资料」分类与宠物档案是两种内容，不自动联动。
- 提醒能力后端已经存在，但当前不作为独立一级功能展示。
- 独立「计划」不再是单独功能，计划类内容统一进入待办。

## 17. 关键闭环

### 进入一个共同空间

```text
微信登录
→ 进入自己的共同空间，或输入邀请码加入其他空间
→ 成为创建人 / 共创人
→ 设置默认空间
→ 进入共同生活内容
```

### 从首页完成一件生活小事

```text
首页摘要或快捷入口
→ 进入待办 / 库存 / 下厨 / 宠物
→ 完成一次记录或状态变更
→ 首页摘要同步更新
```

### 两个人一起决定吃什么

```text
菜谱本
→ 选菜并加入本地加购区
→ 调整人份、餐次、留言
→ 提交共享用餐订单
→ 另一位成员看到订单并共同备菜
→ 逐项勾选食材
→ 进入做饭模式
→ 吃完归档
```

### 记录宠物照护

```text
选择宠物
→ 记录今天吃了什么、喝水、便便或尿尿
→ 记录洗护、驱虫或成长事件
→ 查看时间线、月历和体重趋势
```

### 管理家里的物品

```text
新增物品
→ 记录数量与位置
→ 查看临期状态
→ 使用、丢弃或归档
→ 需要时从历史记录恢复
```

### 保存生活内容

```text
选择生活点滴或重要记录
→ 写入文字和最多 9 张图片
→ 选择空间可见或仅自己可见
→ 在时间线中查看和编辑
```

## 18. 给设计 Agent 的任务

请根据以上能力，重新设计「时刻见」小程序的信息架构、首页、导航、核心页面、关键状态和交互流程。

可以调整页面组织、主次关系、卡片形式、导航方式和视觉语言，不需要兼容现有页面布局或视觉样式。需要保留功能能力、共同空间的数据边界、创建人/共创人的关系，以及记录共享/私密、菜谱点单/备菜、宠物时间线等核心闭环。

请减少冗余文案，让用户能快速知道当前空间发生了什么、现在能做什么、下一步可以做什么。
