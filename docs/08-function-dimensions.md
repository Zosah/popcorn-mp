# 时刻见｜功能维度清单

> 用途：交给设计 Agent 了解当前小程序的功能范围，用于讨论首页功能布局。
>
> 当前阶段：前端 MVP / 微信体验版。短期 1–2 人使用，后期可能逐步扩展。
>
> 本文只整理功能维度，不包含视觉方案和布局建议。

## 1. 产品定位

时刻见是一个面向情侣、家庭、养宠家庭和亲密小圈子的共同生活空间。

它把共同生活中的记录、物品、计划、吃饭和宠物照护放在同一个空间里。

> 把普通日子里的记录、家务、计划和陪伴，安放在一起。

当前一级导航：

| 入口 | 主要职责 |
| --- | --- |
| 家 | 生活状态汇总和各功能入口 |
| 库存 | 家庭物品、有效期和生命周期管理 |
| 记录 | 生活记录和重要资料 |
| 我的 | 账号、共同空间、成员、邀请和设置 |

二级功能：待办与小计划、今天吃什么、宠物照护、空间成员、邀请、提醒设置。

## 2. 功能维度

### A. 账号与共同空间

**解决的问题**

让两个人或一个亲密小圈子共享同一份生活数据。

**功能**

- 微信登录、Demo 本机登录。
- 用户昵称、头像色调和个人资料。
- 默认共同空间。
- 空间成员列表。
- Owner / member 身份。
- 空间名称修改。
- 10 位一次性邀请码。
- 邀请码预览、复制、分享和加入空间。
- 退出登录。
- Demo 数据重置。

**当前状态**

- 账号、资料、会话、空间、成员和邀请已接真实后端。
- 支持多人共享同一个空间。

---

### B. 生活记录

**解决的问题**

保存日常碎片、照片和需要长期查找的重要资料。

**功能**

- 生活点滴时间线。
- 新建、编辑、删除记录。
- 标题、正文、图片和图片说明。
- 记录详情。
- 私有图片存储。
- 可见范围：
  - 空间成员可见。
  - 仅自己可见。
- 最近记录。
- 重要记录分类：
  - 家的资料。
  - 健康资料。
  - 宠物资料。
  - 其他资料。

**当前状态**

- 已接真实后端和 COS。
- 支持多人共享、私密内容、冲突处理和软删除。

---

### C. 家庭库存

**解决的问题**

知道家里有什么、放在哪里、什么时候过期，以及是否已经消耗。

**功能**

- 物品列表与搜索。
- 新增、编辑、查看和删除。
- 数量与单位。
- 购买日期、开封日期和到期日期。
- 存放位置与备注。
- 当前库存与历史记录。
- 有效期筛选：全部、已过期、三天内、七天内、无有效期。
- 物品分类：
  - 食品、饮料、冷冻、调味。
  - 日用、药品、宠物、其他。
- 存放位置：
  - 冰箱、冷冻、厨房、客厅。
  - 卫生间、储藏、其他。
- 生命周期操作：
  - 消耗。
  - 丢弃。
  - 归档。
  - 历史恢复。

**当前状态**

- 已接真实后端。
- 支持空间成员共享。

---

### D. 待办与小计划

**解决的问题**

集中管理生活中的安排、准备事项和轻量记录。

**通用功能**

- 全部视图和分类筛选。
- 新增、编辑、删除。
- 完成 / 重新打开。
- 截止日期。
- 完成进度与统计。
- 旅行准备清单逐项勾选。
- 账单自动视为完成，不计入未完成待办。

**五个功能子类**

| 子类 | 主要能力 |
| --- | --- |
| 旅行准备 | 目的地、准备清单、截止日期、逐项勾选 |
| 小计划 | 标题、备注、计划日期、完成状态 |
| 健身 | 运动名称、时长、热量、粗略估算 |
| 今天吃什么 | 早餐 / 午餐 / 晚餐 / 加餐、随机推荐、生成待办 |
| 我们的账单 | 金额、购买地点、备注、总支出统计 |

**当前状态**

- 已接真实后端。
- 支持空间共享、准备项勾选、完成/重开、版本冲突和软删除。

---

### E. 今天吃什么 / 菜单

**解决的问题**

保存常做的菜、食材和步骤，降低日常做饭与选择成本。

**功能**

- 菜单列表。
- 新建、编辑和删除菜单。
- 菜名、描述、用餐人数和烹饪时长。
- 食材清单：
  - 名称。
  - 用量。
  - 来源。
  - 是否备齐。
- 烹饪步骤。
- 调整用餐人数。
- 开始做饭流程。
- 菜单图片。

**当前状态**

- 已接真实后端和私有 COS。
- 支持空间共享、菜单图片、版本冲突和软删除。

**与待办中“今天吃什么”的区别**

- 菜单：收藏菜谱、食材、步骤和烹饪过程。
- 待办中的“今天吃什么”：决定这一餐吃什么，并生成一条安排。

---

### F. 宠物照护

**解决的问题**

把宠物档案、健康事件、周期照护、日常记录和用品偏好集中在一起。

**功能**

- 多宠物切换与添加。
- 宠物基础档案：
  - 名字、猫 / 狗 / 其他。
  - 品种、性别、生日。
  - 到家日期、绝育日期。
- 体重记录。
- 照护事件：
  - 疫苗、绝育、洗护。
  - 生病、就诊、外出。
  - 体内驱虫、体外驱虫。
- 照护事件详情。
- 周期照护与下次日期：
  - 疫苗，默认 365 天。
  - 洗护，默认 30 天。
  - 体内驱虫，默认 90 天。
  - 体外驱虫，默认 30 天。
  - 周期支持 1–3650 天，可自定义；完成后自动推进下次日期。
- 宠物照护月历。
- 今日日常记录：
  - 吃饭、喝水、便便、尿尿。
- 宠物用品清单：
  - 主粮、罐头、冻干、汤包、猫砂。
- 用品状态：
  - 正在用、爱吃 / 好用。
  - 吃过 / 用过、种草、拔草。

**当前状态**

- 已接真实后端和私有 COS。
- 支持空间共享、周期照护自动推进、版本冲突和软删除。
- 医疗内容只作生活记录，不作为诊疗建议。

---

### G. 提醒与回顾

**解决的问题**

让临期物品、宠物照护和周期性回顾主动被看见。

**功能**

- 库存临期提醒设置。
- 宠物照护提醒设置。
- 每周回顾设置。
- 默认提醒时间设置。

**当前状态**

- 提醒偏好已接真实后端，并按“空间 + 用户”隔离保存。
- 尚未真正发送微信订阅消息。

---

### H. 个人中心

**解决的问题**

管理个人身份、共同空间、邀请和设置，并查看个人待办进度。

**功能**

- 当前身份和登录状态。
- 昵称、头像色调编辑。
- 账号与登录入口。
- 共同空间入口。
- 空间成员与邀请入口。
- 待办进度卡。
- 提醒设置入口。
- Demo 数据重置。

**当前状态**

- 账号、资料、空间、邀请和待办摘要已接真实数据。

## 4. 需要设计 Agent 知道的功能事实

- 首页是唯一的生活状态聚合页。
- 首页当前涉及 7 个维度：空间、记录、库存、待办、吃饭、宠物、提醒。
- 生活记录同时承担情绪表达和重要资料保存。
- 待办同时包含任务、旅行准备、健身、餐食和账单。
- “今天吃什么”在菜单模块和待办模块中各承担一部分能力。
- 库存、待办、生活记录、菜单、宠物和提醒偏好已经按空间多人同步。
- 提醒设置暂未接入微信订阅消息发送。
- 短期面向 1–2 人，后期需要扩展到更多亲密小圈子。
