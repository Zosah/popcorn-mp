# 库存配图改版：占位状态 + 异步生图（产品设计 v0.1）

> 2026-11-25 · 待拍板，未动代码

## 一、我理解你要的三件事

1. **彩色图标池不要了。** 那 174 个 Fluent 图标语义经常对不上（鸡蛋配到「线」、豆腐配到「奶酪」），风格偏贴纸，和真实照片混在同一个列表里会显得廉价。库存的门面应该是**真实照片或 AI 实拍图**，不是图标。
2. **没图时要有「体面的空白」。** 统一占位图 + 一句「AI 自动补充中」，让用户知道这是过渡状态，不是最终结果，也不是他忘了填。
3. **生图换 CogView-4 + 全异步。** CogView-4 单价 ¥0.06（现用 seedream ¥0.20），无水印，但耗时 10–20 秒、限流 5 RPM。这个组合决定了**不能点着等**：点完立刻返回，后台排队生成，好了再自动回填。

## 二、设计原则

| 原则 | 含义 |
|---|---|
| 占位是状态，不是内容 | 占位图不承载识别信息，只承载体面；不要试图用图标"猜"它是什么 |
| 生成是后台任务 | 用户的操作（保存）和系统的耗时（生图）解耦，任何点击都不该等 20 秒 |
| 钱花在"确实需要"的地方 | 同名同品类复用一张；只对真没图的条目生成 |
| 失败对用户隐形 | 失败退回占位，可手动重试，不弹错误吓人 |

## 三、无图状态的展示规则

| 位置 | 表现 |
|---|---|
| 库存列表卡片 | 统一占位插画（浅暖底 + 简笔箱体），**不显示文案**，保持列表干净 |
| 库存在途状态 | 占位图右上角一个 6rpx 的呼吸点，表示"正在补充" |
| 物品详情页 | 占位图 + 一行淡字「AI 正在补充示意图，稍后自动出现」 |
| 首页「家里 · 家庭库存」 | 用功能插画（箱子），不再用某一物品的图标 |
| 编辑页 | 保留「没有照片？生成示意图」，点击即提交任务，不再是转圈等结果 |

## 四、异步任务状态机

```
queued ──► generating ──► done      → 回填 media，列表/详情自动出图
   │            │
   └────────────┴──────► failed    → 回到占位，用户可手动重试
```

**触发时机**（三种入口，共用一个队列）

1. **保存时自动**：新增/编辑物品且 `imageMediaId` 为空 → 自动入队（用户什么都不用点）
2. **手动换一张**：编辑页点「生成示意图」→ 入队，跳过缓存
3. **暂不做**：全库扫描补图（先观察自动触发够不够）

**用户看到的**

```
点保存 → 「已保存」toast（立刻）
      → 列表该物品显示占位 + 呼吸点
      → 20 秒内后台完成 → 下次进列表已经是图（详情页停留时会自动替换）
```

## 五、限流、排队与成本

| 项 | 取值 | 理由 |
|---|---|---|
| worker 并发 | 1 | 5 RPM 打不满，但绝不 429 |
| 调用间隔 | 12 秒 | 5 RPM 折算 |
| 同 topic 去重 | 队列里不允许两个相同 `kind:category:topic` | 防重复付费 |
| 单空间每日上限 | 30 张 | 按 ¥0.06 算每天最多 ¥1.8 |
| 失败重试 | 2 次（5s / 15s），仍失败即 `failed` | 不做自动换模型（seedream 贵 3 倍且风格不一致） |
| URL 处理 | 生成后立刻下载转存自己的 COS | 智谱返回的签名 URL 约 7 天过期 |

## 六、图标池怎么处置

- **库存链路彻底移除**：卡片、详情、首页家里，都不再调用 `resolveInventoryIcon`
- **代码不删**：菜单、宠物、分类默认图还在用，删了会牵连
- **字段保留**：`item.iconKey` 不动，历史数据不迁移
- **回滚开关**：加一个 `USE_ICON_POOL = false` 常量，真出问题一行切回

## 八、需要你拍板的三件事

1. **保存时自动生成，还是必须手动点？**
   我建议自动（用户不用学新操作），并配 30 张/天的空间上限。
2. **列表里要不要显示「AI 补充中」字样？**
   我建议列表只放占位图（不写字，避免噪音），详情页才显示这句。
3. **失败要不要自动重试 3 次再降级？**
   我建议只重试 2 次就停，失败回到占位，用户可手动重试——不自动切回 seedream，避免成本悄悄翻 3 倍。
