# 生活记录 1.22.0 真机验收清单

> 用途：验证私密图片权限、共享可见范围、弱网恢复和图片生命周期。
>
> 当前版本：`1.22.0`
>
> 验收环境：微信体验版或最新预览包
>
> 验收人：guzhzogu(古志周)

## 1. 前置条件

- 使用两个真实微信账号 A、B。
- 两个账号加入同一个共同空间。
- A 至少有 1 张本地图片可用于上传。
- 手机电量充足；验收前记录当前网络状态。
- 不需要记录 Token、Cookie、OpenID、图片签名地址或数据库密码。

## 2. 私密记录图片

1. A 新建一条生活记录，可见范围选择「仅自己」。
2. A 上传一张图片并保存。
3. A 在记录列表和详情中确认缩略图、原图正常显示。
4. B 刷新同一空间的生活记录。
5. 记录 B 是否能看到该记录、缩略图或详情入口。

通过标准：

- A 可以正常查看记录和图片。
- B 看不到 A 的私密记录，也无法从页面取得图片。
- B 即使知道记录或媒体标识，也不能读取图片。

## 3. 共享记录图片

1. A 新建一条生活记录，可见范围选择「空间成员可见」。
2. A 上传另一张图片并保存。
3. B 刷新同一空间的生活记录。
4. B 打开记录详情并检查缩略图和原图。

通过标准：

- B 可以看到该共享记录。
- 缩略图和原图均能正常加载。
- A、B 看到的图片内容一致。

## 4. 弱网与重试

1. A 在表单中选择一张图片。
2. 关闭手机网络或切换到明显不稳定的网络。
3. 执行上传或保存。
4. 恢复网络，点击页面提供的重试或重新加载入口。

通过标准：

- 失败时出现可理解的网络提示，页面不崩溃、不丢失已填写文字。
- 失败后可以继续编辑，不残留半张图片。
- 网络恢复后，上传或加载可以成功完成。
- 编辑页加载失败时出现「重新加载」入口。

## 5. 图片替换与移除

1. A 打开一条已有图片的记录并进入编辑。
2. 替换为新图片，保存后重新进入详情。
3. 再次编辑并移除图片，保存后重新进入详情。

通过标准：

- 替换后列表和详情展示新图片。
- 移除后不再请求或展示旧图片。
- 无图片时页面使用占位或降级布局，不出现破图。
- 其他空间成员刷新后看到与 A 相同的最终状态。

## 6. 证据记录

建议保留以下截图：

- A 的私密记录详情。
- B 看不到私密记录的生活记录页。
- B 可查看共享记录图片的详情页。
- 弱网上传失败提示。
- 弱网编辑页加载失败与重试入口。
- 图片替换后的详情页。
- 图片移除后的详情页。

截图不要包含手机号、微信账号、Token 或其他敏感信息。
